Replacer 2 for Sweet Home 3D
----------------------------

Replacer ("Replace furniture") is a plug-in for Sweet Home 3D, a free interior
design application available at https://www.sweethome3d.com. It replaces the
selected furniture (or all the matching pieces) with another piece of furniture,
keeping the properties you choose to copy (position, angle, size, level...).

This archive contains the compiled plug-in. Its source code is available at
https://github.com/OliMartinez/Replacer
Requirements: Sweet Home 3D 6.5 or later and Java 8 or later.

To install it, double-click this file with Sweet Home 3D installed, or copy it into
the plug-ins folder of Sweet Home 3D and restart the application. That folder
depends on your system:
- under Windows, C:\Users\<user>\AppData\Roaming\eTeks\Sweet Home 3D\plugins,
- under macOS, Library/Application Support/eTeks/Sweet Home 3D/plugins in your user folder,
- under Linux and other Unix, .eteks/sweethome3d/plugins in your user folder.
